# jornal-ana-neri

Este repositório possui o projeto compactado em `create-website-jornal-ana-neri.zip`.

Para organizar o código em uma estrutura de pasta no repositório, use o script abaixo:

```bash
chmod +x scripts/extract-project.sh
./scripts/extract-project.sh
```

O conteúdo será extraído para a pasta `site/` e o repositório ficará pronto para revisão e publicação.
